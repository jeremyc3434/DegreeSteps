# Course-first library and source coverage

My courses can be used before choosing a degree. It stores interests, plans, in-progress courses and completed source records in the same private v3 learning library. Saving a listing creates status `saved`; it never awards credits or school confirmation. Unknown source credits and units remain null. Completion requires actual positive source credits and semester/quarter units; substantive record edits clear stale evaluation claims. Original courses, notes, saved degree versions and per-program choices remain intact.

The initial snapshot contains 218 records: official Sophia (86), StraighterLine (82), CLEP (34), and 16 reviewed Study.com course references. Full Study.com directory import was unavailable, so those references are explicitly scoped. Additional provider directories are linked from source coverage. This is not an exhaustive catalog of every provider. Some directory listings do not publish credits or current recommendation details; unknown facts remain unknown rather than becoming free, credit-bearing, or automatically transferable.

`import-course-catalog.py` extracts directory names and URLs and retains content hashes, check dates, scope and counts. It can refresh its three directory adapters with `--fetch`; default builds use the checked-in snapshot. Minimum counts, atomic replacement and a 20% drop guard prevent silent empty imports. Enrichment uses exact provider plus title or a unique exact official course URL from an existing reviewed map. Curated codes are stored as `mappingCode`, separate from a provider-published `code`. Credit basis is explicit. No course is broadly labeled ACE-accredited; recommendation status and receiving-degree applicability remain separate checks.

Course-first degree discovery creates candidate scenarios without setting an active degree. It evaluates completed records separately from a joint prospective collection. The joint fit inserts known, identified non-earned courses hypothetically one at a time while retaining prior completed work and validating degree credit rules. Overlapping courses cannot inflate aggregate placement. It is a feasible allocation under the current partial map, not a guarantee of the global optimum. Unknown records and unavailable mappings remain evaluation questions. Individual matrix cells still explain potential uses independently.

Only an explicit Use this plan action selects a degree. Valid collection choices can become proposed course selections; original saved records stay unearned. Saving interests does not complete the prior-credit task or invalidate an academic plan review. Source options generated by degree planners cannot overwrite a library record's saved status or fill its unknown credits. School confirmation always remains tied to the exact receiving degree.

Detailed fit currently covers four partial course maps: Liberty residential business, Liberty general Criminal Justice online and residential, and TESU general management. The official program directory remains available for exploration, with unmapped degrees visibly awaiting evaluation. Broader provider and degree-map coverage is ongoing work. No runtime AI service is called by browsing, saving or matching.
