# DegreePath photography credits

Each official photo page below explicitly marks the photograph as free under the [Unsplash License](https://unsplash.com/license/). The license permits commercial website use, downloading, self-hosting and modification; attribution is appreciated but not required. ## Production handling

All three official photo pages and the Unsplash license were reviewed for this release. The parent implementation downloaded and visually inspected the selected files, then generated local WebP assets for responsive delivery. The final image IDs should remain traceable to the original CDN sources above. Resizing, compression and layout cropping do not establish any claim about the pictured people’s educational history, finances, family situation or use of DegreePath. No generated photographs or fabricated customer testimonials are used.

Earlier Pexels candidates, the posed orange-folder portrait and other unused writing/technology photos were not selected for this release and are not credited as production assets.
