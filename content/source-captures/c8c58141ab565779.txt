Objective:
The course objective is to build mastery in database terminology and concepts, including using popular notational systems to design database schemas with usability and data integrity in mind. Through a study of foundational SQL commands, students learn to create and connect tables, query for data across multiple tables, create indexes to optimize data retrieval, and perform basic administrative tasks that ensure security and reliability.
Learning Outcomes:
Demonstrate mastery of the concepts of the entity-relationship model and normalization technique.
Apply basic Create, Read, Update, and Delete interactions with a SQL database.
Identify data security requirements for managing a relational DBMS.
Demonstrate deeper understanding of the concepts of the relational data model in its modern use.
Evaluate resources for complex SQL database interactions.
